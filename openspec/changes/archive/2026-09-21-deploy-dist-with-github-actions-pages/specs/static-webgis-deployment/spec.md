## ADDED Requirements

### Requirement: GitHub Pages serves the CI-built distribution artifact
The system SHALL publish the WebGIS to GitHub Pages from the production `dist` artifact built by GitHub Actions, not by serving repository source files directly.

#### Scenario: Deploy from GitHub Actions artifact
- **WHEN** changes are pushed to the default deployment branch
- **THEN** the deployment workflow builds the static WebGIS application
- **AND** GitHub Pages serves the generated `dist` artifact as the published site

#### Scenario: Published page uses bundled assets
- **WHEN** a user opens the GitHub Pages URL for the repository
- **THEN** the loaded HTML references bundled JavaScript and CSS assets generated by the production build
- **AND** it does not reference unbundled source files such as `/src/main.tsx`

#### Scenario: Repository base path is preserved during CI build
- **WHEN** the deployment workflow builds the application for GitHub Pages
- **THEN** generated asset URLs use the repository base path `/GeoBrasil/`
- **AND** static geodata assets remain resolvable from the published page
